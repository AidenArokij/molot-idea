# molot. — прототип мобильного приложения (PWA)

Интерактивный макет 17 экранов для кофеен molot. (Красноярск, Ачинск). Все данные демонстрационные.

## Что внутри `app/`
- `data.js` — демо-меню (по Instagram-историям от 8 сентября), филиалы, акции, темы. Не актуальный прайс.
- `api.js` — имитация серверной части: пересчёт цен, стоп-лист по точкам, промокоды, бонусы, идемпотентность заказов.
- `app.js` — интерфейс и роутер (17 экранов, шторка настройки напитка).
- `sw.js` — Service Worker (сначала сеть, кеш с версией как запас).
- Шрифты лежат в `fonts/`, внешних зависимостей нет.

## Адаптивность
Телефон: нижняя панель, одна колонка. Компьютер (от 900 px): верхнее меню, списки в две колонки, карточка с фото слева, настройка напитка окном по центру.

## Экраны
Главная · Меню · Категория · Карточка · Настройка напитка · Корзина · Оформление · Филиалы · Статус заказа · Вход · Профиль · История заказов · Карта лояльности · История бонусов · Акции · Избранное · Настройки.

## Что в макете показано честно
- Цена в заказе считается «сервером», а не клиентом.
- Позиции из стоп-листа точки блокируют оформление и объясняют почему.
- Заказ создаётся один раз по ключу идемпотентности. В настройках есть демо-режим «потерять ответ сервера»: повторная отправка не создаёт дубль.
- Бонусы начисляются один раз и только после выдачи заказа; при отмене возвращаются.
- Состав, КБЖУ и фото не выдуманы: блоки без данных помечены.

## Что не подключено
Онлайн-оплата, реальная касса, система лояльности, SMS (код входа в демо: 1234), push-уведомления, админ-панель.

## Запуск

    cd app && python3 -m http.server 8000

Публикуется на GitHub Pages после слияния в `main` (см. `.github/workflows/pages.yml`).
