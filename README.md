# molot. — идея сайта / PWA-приложения

Мобильный прототип для кофеен molot. (Красноярск, Ачинск). Один код — и сайт, и «приложение» на домашнем экране (PWA).

- Меню из Instagram-историй (хиты и новинки отмечены)
- Карта лояльности (10-й кофе в подарок)
- Предзаказ к времени
- Точки и режим работы
- «Настроение сезона»: 5 стилей переключаются в один клик (см. `THEMES` в `app/menu.js` и переменные в `app/styles.css`)

## Запуск

    cd app && python3 -m http.server 8000

Откройте http://localhost:8000 на телефоне (или в режиме мобильного экрана в браузере). Чтобы поставить как приложение, нужен HTTPS (например, GitHub Pages).

Прототип: заказы и штампы хранятся только в браузере, ничего не отправляется.
